# План перевірки Dehaze Media Lab — Web 1.0

Це лабораторний вебзастосунок; він не змінює APK і не керує польотами.

## На комп'ютері

1. Запустіть `RUN_WINDOWS.bat`, відкрийте `http://localhost:8080/`.
2. Оберіть JPEG-фото зі світлими й темними ділянками. Переконайтеся, що справа вказано `GPU: WebGL активний`.
3. Виберіть `MANUAL`, перевірте M1–M15 та LOW/MEDIUM/HIGH. Зміна алгоритму має змінювати праву половину порівняння.
4. Перемкніть AUTO 1.0 → AUTO 2.0 → OFF. OFF має давати оригінальний кадр.
5. Змініть профіль, яскравість, контрастність, насиченість, захист неба й деталізацію. Перевірте експорт PNG.
6. Відкрийте MP4 (H.264), натисніть PAUSE, змініть алгоритм. На паузі кадр має залишатися тим самим, але обробка має оновлюватися.
7. Натисніть -10/+10 і перемістіть повзунок таймлайну; перевірте Play/Stop і зміну швидкості.

## На планшеті Android / iPhone

1. Відкрийте розміщений на HTTPS-сайті застосунок (GitHub Pages) в Chrome / Safari.
2. Натисніть `Камера`; дозвольте доступ. Виберіть задню камеру. Перевірте фактичний розмір кадру в панелі метрик.
3. Встановіть "Макс. доступна", зафіксуйте FPS та затримку на око. За потреби зменште обробку до 1080p/720p.
4. Перемикайте DAY/NIGHT/AUTO та AUTO 1.0/2.0. Зафіксуйте різницю на скріншотах.
5. Переверніть телефон із портретної орієнтації в альбомну; переконайтеся, що зображення не розтягується.
6. Зафіксуйте на відео збої: зависання, зелений/чорний екран, втрату камери, перегрів, неправильні кольори.

**Важливо:** показник `CPU-час кадру` — це час JS-викликів, не справжня затримка GPU чи end-to-end latency.
