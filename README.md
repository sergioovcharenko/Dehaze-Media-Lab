# Dehaze Media Lab — Web 1.0

**Окремий вебпроєкт**, НЕ частина QGroundControl і НЕ APK. Призначений для перевірки алгоритмів на локальних фотографіях, відеофайлах та живому відео з камери iPhone/Android/ПК.

## Запуск

1. Розпакуйте папку або завантажте файли в **окремий GitHub-репозиторій** `Dehaze-Media-Lab`.
2. Для локального запуску на Windows, коли встановлено Python: відкрийте термінал у папці, запустіть `python -m http.server 8080` і відкрийте **http://localhost:8080/**.
3. На телефоні використовуйте **HTTPS**, наприклад GitHub Pages: `Settings → Pages → Deploy from branch → main / (root)`.
4. Натисніть «Фото», «Відео» або «Камера». Дозвольте браузеру доступ до камери, коли він запитає.

> Відкривати `index.html` напряму через `file://` не можна: модуль JS/завантаження GLSL можуть блокуватися браузером.

## Функції

- Фото: оригінал/обробка/50:50/два кадри, PNG-експорт.
- Локальне відео: Play, Pause, Stop, -10/+10 с, повне перемотування таймлайном, швидкість відтворення, експорт кадру. **На паузі алгоритми можна перемикати**.
- Камера: запит на найкращу доступну якість (до 3840×2160), вибір і зміна камери, індикація фактичної роздільності. **Якість та доступ до об'єктивів контролює ОС і браузер; 4K не гарантується.**
- GPU: WebGL 1.0, порт алгоритмів з **QGS TEST 16**: 15 ручних режимів M1–M15 + AUTO 1.0 (M14) та AUTO 2.0 (M16). `src/shaders/qgc-test16-reference.frag` — незмінений еталонний Qt-шейдер, а `src/shaders/dehaze-webgl.frag` — вебпорт із додатковими налаштуваннями.
- DAY/NIGHT/AUTO: додаткова корекція тіней у NIGHT; автоматичне визначення за середньою яскравістю з гістерезисом. Не є класифікатором погодних умов.
- LOW=35%, MEDIUM=65%, HIGH=100%, сила 0–100%; профілі серпанку; контрастність, яскравість, насиченість, захист світлих ділянок, деталізація.
- Зберігає **лише параметри** в локальному сховищі браузера. Медіафайли не завантажуються на сервер і не зберігаються в сховищі.
- PWA: після першого завантаження з HTTPS можна використовувати основні можливості офлайн (за підтримки браузером). Камера також потребує дозволу.

## Межі та якість

- Інтерфейс і GLSL експериментальні. Деякі режими — наближення, а не повні дослідницькі алгоритми (CLAHE-like, Retinex-like тощо).
- WebGL-порт зберігає логіку гілок з TEST 16, але результат може відрізнятися від Qt через колірний простір, драйвер GPU, відеодекодер, фільтрацію та додаткові посткорекції.
- Для відео 1080p/4K на слабших пристроях можливі пропуски кадрів. У меню «Обробка» можна зменшити фактичну роздільність вихідного кадру, незалежно від якості захоплення камери.
- «CPU-час кадру» **не є фактичним часом завершення GPU**. Точну затримку кадрів та MTF тут не вимірюють.
- На Safari або старих Android браузерах не всі відеокодеки підтримуються. Рекомендовано MP4 (H.264) для сумісності.
- Немає керування БпЛА, телеметрії чи UDP-відео QGC у цьому вебпроєкті.

## GitHub Pages

Створіть **новий порожній репозиторій** `Dehaze-Media-Lab`, завантажте в нього файли **з кореня** цього архіву (не папку-обгортку). У `Settings → Pages` задайте `main` та `/ (root)`. Через декілька хвилин з'явиться HTTPS-сайт. Ніяких змін у `QGS DEHAZE CUSTOM`/APK це не вносить.
